1. What is PKCE?
- **PKCE (Proof Key for Code Exchange)** is a security mechanism used with OAuth 2.0, especially for browser and mobile applications where securely storing a client secret is difficult. When a login starts, the client generates a random secret called a **code verifier** and creates a **code challenge** by hashing the verifier with SHA-256. The client sends the code challenge to the authorization server (such as Google), while keeping the verifier secret. After the user successfully logs in, the authorization server sends back an **authorization code**. The client then sends this code along with the original code verifier to the authorization server. The server hashes the verifier again and compares it with the original code challenge; if they match, it exchanges the authorization code for tokens, otherwise the request is rejected. This means that even if an attacker intercepts the authorization code, they cannot use it without the secret code verifier. In short, **PKCE binds the authorization code to the client that originally started the authentication flow**, preventing stolen authorization codes from being exchanged for tokens.
